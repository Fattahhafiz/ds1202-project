# ds1202-project
# DS1202 AS02 – Server Access & Git Proficiency

## 1. Project Overview

This project is part of the DS1202 ICT Infrastructure Basics assignment. It demonstrates secure access to a Linux server using SSH, the use of a Bash shell script to display system information, and Git version control to manage and publish the project to GitHub.

The project uses a `sysinfo.sh` script to generate a system-information report. The script is enhanced through a feature branch and merged back into the main branch.

## 2. System Information Report

The `sysinfo.sh` script reports the following information:

- **Hostname:** The name of the Linux server.
- **Operating System and Kernel:** Information about the operating system and kernel version.
- **Memory Usage:** The amount of memory used and available.
- **Disk Usage:** Information about disk space usage.
- **Logging Enhancement:** An additional logging section implemented as part of the feature branch enhancement.

## 3. Project Directory Structure

The project directory is organised as follows:

```text
ds1202-project/
├── scripts/
│   └── sysinfo.sh
├── docs/
├── logs/
└── README.md
```

- `scripts/` contains the system-information shell script.
- `docs/` is used to store project documentation.
- `logs/` is used for log files generated by the script, if applicable.
- `README.md` explains the project and how to use it.

The project directory is assigned appropriate permissions using `chmod 755`.

## 4. Setup Instructions

### Step 1: Generate an SSH Key Pair

Generate an Ed25519 SSH key pair on your local computer:

```bash
ssh-keygen -t ed25519 -C "your.email@pb.edu.bn"
```

Follow the prompts to save the key pair. Keep the private key secure.

### Step 2: Copy the Public Key to the Server

Copy the public key to the Linux server:

```bash
ssh-copy-id username@<lab-server>
```

Replace `username` and `<lab-server>` with your actual server username and server address.

### Step 3: Connect to the Linux Server

Log in using SSH:

```bash
ssh username@<lab-server>
```

After the public key has been configured correctly, the login should work without entering the account password.

### Step 4: Create the Project Directories

Run the following command on the server:

```bash
mkdir -p ~/ds1202-project/{scripts,docs,logs}
chmod 755 ~/ds1202-project
```

### Step 5: Make the Script Executable

Ensure the script has execute permission:

```bash
chmod +x ~/ds1202-project/scripts/sysinfo.sh
```

## 5. How to Run the Script

Navigate to the project directory:

```bash
cd ~/ds1202-project
```

Run the system-information script:

```bash
./scripts/sysinfo.sh
```

The script displays the system-information report in the terminal. The enhanced version includes the additional logging section implemented for this assignment.

## 6. Git Workflow

Git was used to track changes, create a feature branch, merge the enhancement, and publish the project to GitHub.

### Step 1: Initialise the Repository

```bash
git init
git add .
git commit -m "Add directory structure and sysinfo script"
```

### Step 2: Create the Feature Branch

```bash
git switch -c feature-logging
```

The feature branch was used to enhance the system-information script.

### Step 3: Commit the Enhancement

After editing and testing the script:

```bash
git add scripts/sysinfo.sh
git commit -m "Add logging section to sysinfo"
```

### Step 4: Merge the Feature Branch into Main

```bash
git switch main
git merge feature-logging
```

This merges the changes from `feature-logging` into `main`.

### Step 5: Push the Repository to GitHub

Add the GitHub repository as a remote if it has not already been configured:

```bash
git remote add origin git@github.com:<your-username>/<your-repository>.git
```

Push the main branch and feature branch:

```bash
git push -u origin main
git push origin feature-logging
```

Replace the placeholders with your actual GitHub username and repository name.

### Step 6: View the Git History

To display the commits, branches, and merge history, run:

```bash
git log --graph --oneline --all
```
